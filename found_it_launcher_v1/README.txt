FOUND IT! Destination Launcher V1

ROOT FILE
---------
index-section.html
Paste this section into your main index.html.

INSTALLATION
------------
Place found_it_games_v1 beside index.html.

The launcher links use:
found_it_games_v1/<destination>-found-it.html

The destination pages are self-contained and include:
- 5 missions
- score
- progress bar
- levels
- photo upload preview
- mission completion
- localStorage progress
- reset
- share/copy caption
- responsive layout
- back-to-destinations link

NOTE
----
The browser cannot independently verify that a user physically visited a location.
The "Unlock mission" action is therefore a V1 honor-system game mechanic. The
photo upload is previewed locally and is not uploaded to a server.

The image URLs are remote Unsplash images. For production, replace them with your
own licensed destination photography or local assets.
